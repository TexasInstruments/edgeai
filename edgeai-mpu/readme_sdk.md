# Supported Devices & SDKs

This page lists TI's C7™ NPU-accelerated microprocessors that support TIDL, along with their product information, SDK landing pages, and Linux SDK downloads. Devices are grouped by SoC family: each section heading names the primary device its SDK targets. Similar devices are also listed, so a model compiled for one can be deployed on the others without recompiling.

Additional information is available at [edgeai-tidl-tools](https://github.com/TexasInstruments/edgeai-tidl-tools#supported-devices-and-compatibility).
